# Sound inbox

Drop generated sound files here, then run `python3 tools/install_sounds.py` from the repo folder.

- Name each file as `SOUND-LIST.md` says, for example `toll_317.mp3` or `boss_bride.wav`. Extra words after the name are fine (`toll_317 take 2.mp3`).
- wav, mp3, ogg, flac and m4a all work. The installer trims, levels and converts them.
- Files in this folder are not committed. The converted `.ogg` in the resource pack is what the game uses.

No computer set up for this? Upload the files in the project chat and ask Claude to install them.
